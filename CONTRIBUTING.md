# Contributing to EduTrace

First off, thank you for considering contributing to EduTrace! 

## Ways to Contribute
1. **Reporting Bugs:** Create an issue clearly describing the bug, steps to reproduce, and expected behavior.
2. **Suggesting Enhancements:** Have an idea for a feature? Submit an issue with the "enhancement" tag.
3. **Pull Requests:** 
   - Fork the repository.
   - Create a feature branch `git checkout -b feature/MyFeature`
   - Commit your changes `git commit -m "Add MyFeature"`
   - Push to the branch `git push origin feature/MyFeature`
   - Open a Pull Request!

## Coding Guidelines
- Follow standard Android styling guidelines.
- Add comments where the logic is complex.
- Make sure all Gradle builds run successfully before submitting PRs.
