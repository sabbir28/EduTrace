# EduTrace

EduTrace is an Android application designed to help you track your study progress effortlessly. The application allows you to log your daily study sessions, view your pulse/progress at a glance through the built-in widget, and maintain a robust report of your productivity.

## Features
- **Study Pulse Widget**: See your study status directly from your home screen.
- **Detailed Reports**: Keep a track of your daily, weekly, and monthly productivity.
- **Customizable Appearance**: Native Dark/Light mode support.
- **Localization**: Supports multiple languages for an inclusive experience.
- **Local Storage**: Uses Room Database for fast and secure offline data tracking.

## Tech Stack
- **Min SDK**: 21
- **Target SDK**: 33
- **Architecture**: MVVM
- **Language**: Java / Kotlin
- **Database**: Room Database
- **UI**: Android View Binding & Material Components

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/EduTrace.git
   ```
2. Open the project in Android Studio.
3. Sync project with Gradle files.
4. Build and Run the project onto your emulator or Android device.
